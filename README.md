# 実験レポート用グラフ作成

数値を表に入れるだけで，実験レポート用のグラフを Excel のように作れる Web アプリです．
グラフは裏側で Python（matplotlib）が描いていて，**そのグラフを作る Python コードも画面で見られます**．

- 散布図（点のみ／直線とマーカー）・折れ線・棒グラフ（縦），複数系列に対応
- 画像の大きさを **mm で指定**（レポートに貼る実寸で作れる）
- PNG（150／300／600 dpi）・SVG・PDF で保存，背景は白／透明
- 表示されるコードを `python graph.py` で実行すると，同じグラフが保存される

## 🌐 Web 版（インストール不要・スマホでも使える）

**https://shino1108-17.github.io/report-graph-maker/**

この URL を開くだけで使えます．友達にもこの URL を送れば，そのまま使えます．

- ブラウザの中で Python（[Pyodide](https://pyodide.org/)）が動いて，グラフを描きます．入力したデータはサーバーに送られず，その端末の中だけで処理されます．
- 初めて開いたときは Python と matplotlib の読み込みに **10〜30 秒ほど**かかります（2 回目からは速くなります）．
- 使えるフォントは，同梱の IPAex ゴシック（日本語）と STIX（Times 風）・DejaVu（英数字）です．
  ヒラギノや Times New Roman など Mac のフォントを使いたいときは，下の「手元の Mac で動かす」方法を使ってください．
- Chrome・Safari（iPhone は iOS 15 以降）・Edge で動きます．

## 1. インストール

Python 3.10 以上が必要です．まずコードを手元に持ってきます（初回だけ）：

```bash
git clone https://github.com/shino1108-17/report-graph-maker.git
cd report-graph-maker
```

このフォルダ（`main.py` がある場所）でターミナルを開いて：

```bash
pip install -r requirements.txt
```

> **（おすすめ）仮想環境を使う場合**：ほかのプロジェクトとライブラリが混ざらないように，先に次を実行してから `pip install` します．
> ```bash
> python3 -m venv .venv
> source .venv/bin/activate
> ```
> 次回からは，起動する前に `source .venv/bin/activate` だけ実行してください．

## 2. 起動

```bash
uvicorn main:app --reload
```

ブラウザで **http://127.0.0.1:8000** を開きます．
止めるときはターミナルで `Ctrl + C` を押します．

> VSCode なら「ターミナル → 新しいターミナル」で，このフォルダが開いた状態のターミナルが出ます．

## 3. 使い方

画面は 4 つの部分に分かれています．

| 場所 | 内容 |
| --- | --- |
| 左 | データ入力の表 |
| 中央 | プレビュー（入力が止まって 0.4 秒後に自動で更新） |
| 右 | 設定（見出しをクリックで開閉） |
| 下 | Python コード（「▲ Python コード」で開閉） |

### データを入れる

- **1列目が X，2列目以降が Y（系列）** です．各列の見出し（一番上の行）が系列名・軸ラベルになります．
- セルをクリックして入力します．`Enter` で下のセルへ（最後の行なら行が増えます），`Shift + Enter` で上へ，`Tab` で右へ移動します．
- **Excel からの貼り付け**：Excel で範囲をコピーし，貼り付けたい左上のセルを選んで `⌘ + V`．
  見出しごとコピーした場合は，表の **見出しのセル**（`X` と書いてある列の一番上）を選んで貼り付けます．足りない行・列は自動で増えます．
- **CSV を開く**：見出し行があれば自動で見分けます．Excel の「CSV（コンマ区切り）」形式（Shift_JIS）も UTF-8 も読めます．
- `＋ 行` `− 行` `＋ 列（系列）` `− 列` は，**選択中のセル**の位置で追加・削除します．
- 数値でないセルは赤くなります（全角数字は自動で半角として扱います）．空欄の点は描かれません．

### グラフを整える（右のパネル）

| セクション | できること |
| --- | --- |
| グラフの種類 | 散布図（点のみ）／散布図（直線とマーカー）／折れ線／棒グラフ，プリセット |
| タイトル・凡例 | タイトルの表示と文字，凡例の表示・位置・枠，データラベル（小数点以下の桁数） |
| 軸 | 軸ラベル，最小値・最大値・目盛り間隔（空欄なら自動），対数目盛り，「Y 軸を 0 から始める」，目盛り線（なし／横のみ／縦横），目盛りの向き，軸の枠線，外枠 |
| 系列 | 系列ごとの色・線の種類・線の太さ・マーカーの形と大きさ・塗りつぶし／白抜き |
| 文字・サイズ・保存 | 英数字と日本語のフォント，文字の大きさ，幅・高さ [mm]，解像度，背景，ダウンロード |

**プリセット**

- **レポート用**：白黒（線の種類とマーカーの形で系列を区別），幅 58 mm，文字 7 pt，Times New Roman ＋ 明朝体，目盛りは内向き．系列が 1 つなら凡例なし．
- **Excel 風**：Excel の標準グラフに近い見た目（横の目盛り線，凡例は下，幅 127 mm）．
- **シンプル**：左と下の軸だけの，すっきりした見た目．

**メモ**

- 折れ線・棒グラフは，Excel と同じく X を「項目」として等間隔に並べます（X に文字も使えます）．
  X の値の間隔どおりに描きたいときは「散布図（直線とマーカー）」を使ってください．
- 軸ラベルの単位は `電源電圧 Vcc [V]` のように **[ ] で囲む**のがおすすめです（そうでないと右のパネルに案内が出ます）．
- 文字の中で `$` で囲んだ部分は数式になります．例：`電流 $I_F$ [mA]` → 電流 *I*<sub>F</sub> [mA]，`$V_{cc}$`，`$\Omega$`．
  `$` そのものを表示したいときは `\$` と書きます．
- 入力したデータと設定はブラウザに保存され，次に開いたときに復元されます．「最初からやり直す」で初期状態に戻せます．

### 保存する

- 「文字・サイズ・保存」の **PNG／SVG／PDF** ボタンでダウンロードします．
  - Word に貼るなら PNG（300 dpi 以上）がおすすめ．拡大しても荒れないのは SVG／PDF です．
- 画像は指定した mm ぴったりの大きさで保存されます（余白の自動トリミングはしません）．
  Word では「図の書式設定 → サイズ」で 100% にすると実寸になります．

### Python コードを使う

- 下の「▲ Python コード」を開くと，今のグラフを作るコードが表示されます．
- **コピー**／**.py で保存** ができます．保存した `graph.py` を実行すると，同じグラフが `graph.png` などに保存されます．

```bash
python graph.py
```

- コードにはデータも含まれているので，そのファイルだけで動きます．値や色を書き換えて自分で調整することもできます．

## 4. テスト

```bash
pytest
```

次のことを確かめています．

- 生成したコードを単体で実行すると，指定した mm・dpi どおりの PNG ができる（4 種類のグラフすべて）
- 単体で実行して保存した画像と，サーバーが作った画像がピクセル単位で一致する（表示コードと実際の処理がずれていない）
- 各グラフ種類 × いろいろな設定の組み合わせでエラーが出ない
- 数値以外・データ点数の上限・サイズの上限などの入力がサーバー側ではじかれる
- タイトルや見出しに Python コードを書いても実行されない

## 5. ファイル構成

```
report-graph-maker/
├── main.py              # FastAPI（手元で動かすときのサーバー）
├── api_core.py          # 入力チェック → コード生成 → 描画（サーバー版とブラウザ版で共通）
├── schemas.py           # 設定（JSON）の型と入力チェック
├── codegen.py           # 設定 → matplotlib の Python コード（日本語コメント付き）
├── renderer.py          # 生成したコードを実行して画像にする
├── static/
│   ├── index.html       # 画面
│   ├── style.css
│   ├── app.js           # 表の編集・貼り付け・CSV・自動更新・コード表示（素の JavaScript）
│   └── engine-worker.js # ブラウザ版：Pyodide で api_core.py を動かす（Web Worker）
├── build_site.py        # GitHub Pages 用のサイトを _site/ に組み立てる
├── .github/workflows/pages.yml  # push したらテスト → GitHub Pages に公開
├── tests/test_app.py    # pytest
├── requirements.txt
└── pytest.ini
```

### Web 版の公開のしくみ

`main` ブランチに push すると，GitHub Actions が自動で

1. `pytest` でテスト
2. `python build_site.py` でサイトを組み立て
3. GitHub Pages に公開

を行います（数分で反映されます）．画面は「サーバーがあればサーバーで，なければブラウザの中の Python で」描くので，
同じ `static/` のファイルが手元でも Web 版でも動きます．

手元で Web 版と同じ状態を試すには：

```bash
python build_site.py
```
```bash
python -m http.server 8765 --directory _site
```

ブラウザで http://localhost:8765 を開きます．

### しくみ

```
ブラウザ ──設定(JSON)──▶ api_core.py ─▶ schemas.py で入力チェック
                         │
                         ▼
                    codegen.py が Python コードを生成 ──▶ 画面に表示
                         │
                         ▼
                    renderer.py が「そのコード」を実行 ──▶ 画像（プレビュー・ダウンロード）
```

- **表示するコードと，画像を作るコードは同じ文字列**です．サーバーはコード内の `draw_graph()` と `save_graph()` を呼び出しているだけなので，ずれることはありません．
- サーバーが受け取るのは設定（JSON）だけで，**ユーザーが書いた Python コードは受け取りも実行もしません**．
  タイトルや見出しなどの文字は，必ず Python の文字列（`"..."`）としてコードに埋め込まれるので，コードとして実行されることはありません．
- 入力値はサーバー側でチェックしています（数値以外，2000 行まで，系列 10 個まで，サイズ 20〜300 mm，文字数，選べるフォント・色の形式など）．

### API（参考）

| メソッド | パス | 内容 |
| --- | --- | --- |
| GET | `/` | 画面 |
| GET | `/api/fonts` | この PC で使えるフォントの一覧 |
| POST | `/api/render` | プレビュー画像（PNG, base64）と Python コード |
| POST | `/api/export` | ダウンロード用ファイル（PNG／SVG／PDF） |

## 6. 困ったとき

| 症状 | 対処 |
| --- | --- |
| `command not found: uvicorn` | `pip install -r requirements.txt` が終わっているか確認．仮想環境なら `source .venv/bin/activate` を先に実行 |
| `Address already in use` | すでに起動しています．前のターミナルで `Ctrl + C` で止めるか，`uvicorn main:app --reload --port 8001` で別のポートを使う |
| 画面に「サーバーに接続できません」 | ターミナルで uvicorn が動いているか確認 |
| フォントの選択肢が少ない | 一覧に出るのはこの PC に入っているフォントだけです（IPAex ゴシックは常に使えます）．フォントを追加した後は `~/.matplotlib` フォルダを削除してから再起動 |
| 日本語が □ になる | 日本語のフォントで「IPAexゴシック」などを選んでください |
| 数式のエラーが出る | `$` の数が奇数になっていないか確認．`$` そのものは `\$` と書く |
| Web 版が「準備に失敗しました」になる | インターネットにつながっているか確認して再読み込み．古いブラウザ（iOS 14 以前など）では動きません |
